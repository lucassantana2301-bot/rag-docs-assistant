# Política de segurança

## Versões suportadas

Apenas a última versão publicada (tag mais recente) recebe correções de segurança.

## Como reportar

Encontrou uma vulnerabilidade? **Não abra issue pública.** Use o
[reporte privado do GitHub](https://github.com/lucassantana2301-bot/rag-docs-assistant/security/advisories/new)
com o passo a passo para reproduzir e o impacto estimado.

- Confirmação de recebimento em até 3 dias úteis.
- Correção ou plano de mitigação em até 30 dias, conforme a severidade.
- Crédito no advisory, se desejar.

## Escopo

Prompt injection a partir de documentos indexados, vazamento de chaves de API dos provedores de LLM, upload de arquivos maliciosos (PDF/HTML), bypass da API key e exposição de conteúdo de documentos a quem não deveria ver.
